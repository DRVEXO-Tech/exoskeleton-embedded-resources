功能码 00          发送固件信息等消息

| 位号       | 数据类型 | 说明                   |
| ---------- | -------- | ---------------------- |
| bit：0-3   | uint32_t | 版本号                 |
| bit：4-5   | uint16_t | 当前大包               |
| bit：6-9   | uint32_t | 当前接收字节数         |
| bit：10    | uint8_t  | 当前版本中是否存在断续 |
| bit：11-18 | uint64_t | 设备SN码               |

功能码01                   发送模式等消息

| 位号       | 数据类型 | 说明                                                         |
| ---------- | -------- | ------------------------------------------------------------ |
| bit 0      | uint8_t  | 电源指示：0关机  1开机                                       |
| bit 1      | uint8_t  | 模式选择：0舒适模式 1均衡模式  2运动模式 3极限模式 4阻尼模式 5 休息模式 |
| bit 2      | uint8_t  | 系统力矩：0-100                                              |
| bit 3      | uint8_t  | 电池电量百分比                                               |
| bit4-7     | float    | 主控温度                                                     |
| bit:8-11   | float    | 左电机角度                                                   |
| bit:12-15  | float    | 右电机角度                                                   |
| bit:16-19  | uint32_t | 步数                                                         |
| bit:20     | uint8_t  | 灯光大小（0-100）                                            |
| bit：21    | uint8_t  | 音量大小（0-100）                                            |
| bit：22    | uint8_t  | 助力时机（0-100）                                            |
| bit: 23-26 | float    | 电池温度                                                     |
| bit：27    | uint8_t  | 电池健康度(%)                                                |
| bit: 28-29 | uint16_t | 预计放电时间（min）                                          |
| bit 30-33  | int32_t  | 设备功率(mW)                                                 |
| bit 34     | uint8_t  | 上升步长                                                     |
| bit 35     | uint8_t  | 曲线指数低                                                   |
| bit 36     | uint8_t  | 曲线指数高                                                   |
| bit 37     | uint8_t  | 平缓助力开关                                                 |
| bit 38     | uint8_t  | 左不均衡系数                                                 |
| bit 39     | uint8_t  | 右不均衡系数                                                 |
| bit 40     | uint8_t  | 温度挡位                                                     |
| bit 41     | uint8_t  | 低速模式                                                     |







功能码02                   发送答复消息

| 位号   | 数据类型 | 说明                 |
| ------ | -------- | -------------------- |
| bit：0 | uint8_t  | 0：数据正常1：未成功 |

功能码03                 错误返回

| 位号   | 数据类型 | 说明                           |
| ------ | -------- | ------------------------------ |
| bit：0 | uint8_t  | 气压计    0：正常1：异常       |
| bit：1 | uint8_t  | IMU1     0：正常1：异常        |
| bit：2 | uint8_t  | IMU2     0：正常1：异常        |
| bit：3 | uint8_t  | 外置flash     0：正常1：异常   |
| bit：4 | uint8_t  | fdcan     0：正常1：异常       |
| bit：5 | uint8_t  | 左电机fdcan     0：正常1：异常 |
| bit：6 | uint8_t  | 右电机fdcan     0：正常1：异常 |
|        |          |                                |
|        |          |                                |

功能码04                 状态返回

| 位号   | 数据类型 | 说明                                 |
| ------ | -------- | ------------------------------------ |
| bit：0 | uint8_t  | 0：空闲1：正在进行  2：失败  3：成功 |

功能码05                 芯片UID返回

| 位号      | 数据类型 | 说明     |
| --------- | -------- | -------- |
| bit：0-3  | UID1     | 芯片UID1 |
| bit：4-7  | UID2     | 芯片UID2 |
| bit：8-11 | UID3     | 芯片UID3 |

功能码07         OTA准备开始 （请等待02答复）    

| 位号      | 数据类型 | 说明                                                         |
| --------- | -------- | ------------------------------------------------------------ |
| bit：0-3  | uint32_t | 版本号                                                       |
| bit：4    | uint8_t  | OTA目标：0（主控）1（电池）2（左电机）3（右电机）            |
| bit：5-8  | uint32_t | 数据包大小（总大小）                                         |
| bit：9-10 | uint16_t | seq总个数（每2048个字节为一个大包（seq），最后剩余不足2048也算一个） |

功能码08         OTA数据包（请等待02回复）

| 位号        | 数据类型 | 说明                                                       |
| ----------- | -------- | ---------------------------------------------------------- |
| bit：0-255  | -        | 数据包                                                     |
| bit:256-257 | uint16_t | seq（大包序号，用于掉电，每2048个字节为一个大包，从0开始） |
