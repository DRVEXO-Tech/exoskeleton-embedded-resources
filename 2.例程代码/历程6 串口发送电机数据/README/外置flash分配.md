OTA信息

| 位         | 类型     | 所有OTA信息                     |
| ---------- | -------- | ------------------------------- |
| bit：0-3   | uint32_t | 版本号                          |
| bit：4     | uint8_t  | 更新标志位(0不更新 1更新)       |
| bit：5-6   | uint16_t | 当前版本号总大包数              |
| bit：7-10  | uint32_t | 当前版本bin文件大小             |
| bit：11-12 | uint16_t | 当前版本实际收到的大包数        |
| bit：13-16 | uint32_t | 当前版本实际接收的字节数        |
| bit：17-20 | uint32_t | 总文件的crc32校验               |
| bit：21    | uint8_t  | 是否更新完毕（0已完成 1未完成） |
